# Task Creation Feature

## Objective

Allow users to create and manage tasks through the web application.

## Requirements

- Users can enter a task title.
- Users can provide an optional description.
- Users can assign a priority: Low, Medium, or High.
- Users can save a new task.
- Users receive confirmation after saving.

## Acceptance Criteria

- A task cannot be created without a title.
- A successfully created task appears in the task list.
- Newly created tasks have a default status of Todo.
