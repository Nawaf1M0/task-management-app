
# Changelog

## [0.2.0] - 2026-11-28

### Added

- Automated release management workflow.
- Versioned application release packages.
- SHA-256 release package checksums.
- Automatically generated release notes.
- Automated CodeQL security analysis.

### Changed

- Improved continuous integration and quality gates.
- Introduced reusable workflows and composite actions.
- Improved workflow resource management.

### Security

- Pinned external GitHub Actions to full commit SHAs.
- Disabled checkout credential persistence.
- Configured Dependabot for dependency updates.
- Applied least-privilege workflow permissions.
