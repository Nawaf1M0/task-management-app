# Task Management App

A web application for organizing tasks, managing priorities, and tracking progress.

## Project Goals

- Learn Git and GitHub through practical development.
- Build a functional task management web application.
- Practice branching, commits, and pull requests.
- Implement automated testing and deployment.
- Explore GitHub project management and security features.

## Planned Features

- Create, edit, and delete tasks.
- Mark tasks as completed.
- Assign task priorities.
- Filter tasks by status.
- Save tasks between sessions.
